# 🏓 Pongg Game

A simple Pong-style game built using **Python and Pygame**. Play against a computer-controlled opponent, score points, and enjoy background music and sound effects.

## 🎮 Features

- **Player Controls:** Move the paddle up and down using the Up and Down arrow keys.
- **CPU Opponent:** Play against a computer-controlled paddle.
- **Imperfect CPU:** Randomness is added to the CPU's ball-tracking position, making its predictions imperfect. This gives the player a fair chance to win points instead of playing against a perfect opponent.
- **Score Tracking:** Keep track of the player's and CPU's points.
- **Sound Effects and Music:** Background music and audio effects when points are scored.

## 🛠️ Built With

- Python
- Pygame

## 🚀 How to Run

1. Install Python 3.x.
2. Install Pygame:

   ```bash
   python -m pip install pygame
   ```

3. Clone this repository and open the project folder.
4. Run the game:

   ```bash
   python main.py
   ```

Make sure the required audio files are present in the project folder.

## 🕹️ Controls

| Key | Action |
|---|---|
| ⬆️ Up Arrow | Move paddle up |
| ⬇️ Down Arrow | Move paddle down |
